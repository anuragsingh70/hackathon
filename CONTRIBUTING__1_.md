## How to Contribute

- **Bug Reports** — Open an issue with steps to reproduce and expected vs actual behavior.
- **Feature Requests** — Open an issue describing the problem and your proposed solution.
- **Language Support** — Help add Hindi, Kannada, Tamil, or other Indian languages via `locales/`.
- **Legal Accuracy** — Improve RTI prompt templates, PIO addresses, or legal section references in `prompts/`.
- **UI/UX** — Improve accessibility, mobile responsiveness, or usability for low-literacy users.

## Getting Started

```bash
git clone https://github.com/team-intelli/jansunaai.git
cd jansunaai
cp .env.example .env        # Add your ANTHROPIC_API_KEY
npm install
npm run dev
```

---

## Submitting a Pull Request

1. Fork the repo and create a branch from `main`
2. Make focused, well-tested changes
3. Follow commit conventions: `feat:`, `fix:`, `docs:`, `style:`, `test:`
4. Open a PR with a clear description and link to the related issue

All PRs require review from at least one core team member.

---

## Code of Conduct

Be respectful, inclusive, and constructive. Harassment of any kind will not be tolerated.
